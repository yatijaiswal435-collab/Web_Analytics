# Web Data Analysis Project

## About This Project

This is a beginner-level web data analysis project where I analyzed website traffic and user engagement data using Python.
The main goal of this project was to understand user behavior, traffic sources, and website performance through data visualization and analysis.

## Tools & Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## What I Did

* Loaded and cleaned the dataset
* Handled missing values and formatted the data
* Performed Exploratory Data Analysis (EDA)
* Created different graphs and charts for analysis
* Analyzed user engagement and website traffic patterns
* Found useful insights from the data

## Graphs Used

* Line Graphs
* Bar Charts
* Box Plots
* Heatmaps
* Stacked Bar Charts

## Key Insights

* Direct and Organic Social channels brought the highest number of users.
* Organic Social users showed better engagement on the website.
* Some time periods had higher traffic and user activity than others.
* High traffic does not always mean high engagement.
* Certain channels kept users active on the website for longer time.
* Traffic patterns helped understand user behavior and website performance.

## What I Learned

Through this project, I learned:

* Data cleaning and preprocessing
* Data visualization using Matplotlib and Seaborn
* Exploratory Data Analysis (EDA)
* Finding insights from real-world data
* Understanding website traffic and engagement metrics

## How to Run This Project

1. Clone the repository
2. Install required Python libraries
3. Open the notebook in Jupyter Notebook
4. Run all cells to see the analysis and graphs
